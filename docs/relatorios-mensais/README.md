## 📋 Estrutura Padrão de um Relatório Mensal
Todo relatório nesta pasta deve conter:
1. **Resumo Executivo do Mês:** Síntese em um parágrafo do progresso técnico.
2. **Entregas Consolidadas:** Lista de artefatos e códigos produzidos.
3. **Decisões de Engenharia & Arquitetura:** Resumo das ADRs registradas no período.
4. **Metodologia & Trabalho em Equipe:** Como o time operou (sprints, papéis e rituais).
5. **Próximos Passos:** Metas para o mês seguinte.
