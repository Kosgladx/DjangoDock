## 📌 Como o Time Opera Durante a Sprint

1. **Início da Sprint:** Abertura da sprint na sexta-feira com alinhamento das fatias verticais.
2. **Dia a Dia:** Comunicação ágil via WhatsApp para tirar dúvidas e resolver impeditivos pontuais. Ninguém mexe direto na `main`. Cada um trabalha em sua branch (`feat/...`).
3. **Fechamento e Homologação:** Na sexta-feira seguinte, o Tech Lead (Kauê) valida a subida no Docker PostgreSQL, confere os Pull Requests na `main` e carimba a tag de versão no Git.
